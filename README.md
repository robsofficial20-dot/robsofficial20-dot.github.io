# EASY EDIT GUIDE

You only need to edit **content.json** for normal portfolio changes.

## Change your personal details
Open `content.json` and edit the values inside:
- `site` = name, tagline, intro, location
- `about` = your story, tools and skills
- `projects` = project names, descriptions and image filenames
- `services` = services you offer
- `contact` = email and social links

## Change project photos
Upload your photos into the `assets` folder.

The default project files are:
project-01.jpg
project-02.jpg
project-03.jpg
project-04.jpg
project-05.jpg
project-06.jpg

If you use a different filename, change the matching `image` value in content.json.

## Important
Do not edit index.html unless you want to change the design/layout itself.

After saving your changes in GitHub, GitHub Pages will update the website automatically.
