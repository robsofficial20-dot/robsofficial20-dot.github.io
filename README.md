# Robin Victorino Portfolio
Live site: https://robsofficial20-dot.github.io/

## Replace portfolio images
Create an `assets` folder and upload:
- project-01.jpg
- project-02.jpg
- project-03.jpg
- project-04.jpg
- project-05.jpg
- project-06.jpg

The project cards will automatically display them.

## Edit contact details
Open index.html and replace:
- your@email.com
- @yourusername

GitHub Pages uses the main branch and index.html as the site entry point.
